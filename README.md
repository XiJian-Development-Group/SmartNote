## 1. 快速开始

### 1.1 系统要求

- macOS 15.0 或更高版本。
- 应用使用系统原生框架，不依赖第三方运行时库。

### 1.2 下载应用

请访问 [GitHub Releases](https://github.com/XiJian-Development-Group/SmartNote/releases) 下载最新版本的 ZIP 压缩包并解压。

### 1.3 启动应用

在 Finder 中找到 `SmartNote.app` 并双击打开，或在 Launchpad 中点击图标。应用数据默认保存在本机的 `Application Support/SmartNote` 目录。

## 2. 资料库

### 2.1 导入资料

1. 点击工具栏「添加」→「导入文件」，或在导入面板中拖入文件。
2. 选择「复制到资料库」或「仅创建链接」。
3. 选择要导入的文件后点击「导入」。

当前扫描器识别的扩展名包括：PDF、DOC、DOCX、PPT、PPTX、PNG、JPG、JPEG、GIF、BMP、TIFF、TXT、MD。PDF 会尝试提取内置文本；其他格式的资料会保留文件并在需要时读取。

### 2.2 侧边栏页面总览

当前侧边栏按 `ContentView` 的实际分组和顺序提供：

- **资料库**：全部资料、课件、真题、笔记、收藏。
- **学习**：考点提取、智能阅卷、AI 对话、番茄钟、错题本、背诵卡片、白板。
- **计划**：考试倒计时、复习计划、待办清单、习惯养成打卡。
- **实用工具**：学习统计、社交、放松亿下、日记、文件加密、白噪音、许愿、纪念日、计算器、重复清理。

### 2.3 新建与编辑资料

- 可以从「添加」→「新建资料」创建文字资料。
- 资料详情页支持修改名称、分类、关键词和正文；正文修改会显示为自动保存。
- 图片资料可以从详情页或资料列表的右键菜单触发文字识别（OCR）。

### 2.4 导出资料

在资料详情页点击「导出」，可以：

- 导出为 PDF；
- 导出为纯文本；
- 复制资料内容到剪贴板。

### 2.5 OCR 文字识别

对于图片格式且尚未提取文字的资料，打开详情后点击「文字识别」。识别结果使用本地 Vision OCR，并保存到资料内容中；它不是云端 OCR 服务。

## 3. 学习工具

### 3.1 考点提取

1. 在侧边栏选择「考点提取」。
2. 选择一份资料。
3. 使用本地关键词提取得到候选考点并保存。
4. 配置 AI 后，可以对资料发起 AI 分析。

### 3.2 AI 对话

在「AI 对话」页输入问题，向设置中配置的 LLM 服务发送文本请求。页面也支持附加图片；图片是否直接发送给服务取决于「AI 分析」中的图像理解设置，具体规则见 [6. AI 功能](#6-ai-功能)。

### 3.3 智能阅卷

在「智能阅卷」页选择资料或上传文件，标记用户回答、原题和标准答案，然后向已配置的 LLM 请求批改、解释或类似题目。文件解析和标记结果由当前页面负责，AI 是否可用取决于设置和服务响应。

## 4. 计划管理

### 4.1 复习计划

1. 在侧边栏选择「复习计划」。
2. 创建计划，填写考试科目、日期和复习要点。
3. 按日浏览任务并标记完成。

创建计划时可以请求日历权限并创建 macOS 日历事件。`CalendarService` 也提供提醒事项创建接口，但当前计划创建流程不会自动调用该提醒接口。

### 4.2 待办清单

可以添加、编辑、完成、置顶和删除待办，按标题、描述、标签、分类和状态搜索。待办支持番茄钟关联、手动计时、提醒时间和按活动时间段统计；提醒需要系统通知权限。

### 4.3 习惯养成打卡

创建习惯后按日期打卡，查看连续记录和历史记录。

### 4.4 学习统计

「学习统计」页展示资料数量、资料总大小、考点数量、资料分类占比和最近添加的资料。番茄钟页另有专注时长、科目分布和会话统计。

## 5. 实用工具

### 5.1 日记

- 新建、编辑、置顶、删除和按标题搜索日记。
- 支持分类、日期、图片和关联白板。
- 可启用本地日记正文加密：正文使用 AES-256-GCM，密码、密保问题和密保答案存入 macOS Keychain。
- 加密失败时保存流程会失败关闭，不会把明文当作成功结果写回。
- 加密只覆盖日记正文；标题、分类、日期、置顶状态、关联资料和图片路径等元数据仍是本地明文数据。

### 5.2 白噪音

「白噪音」页提供 6 个内置声源，可分别播放、调节音量和停止全部播放；也支持导入本地音频文件。内置声源由 `AVAudioEngine` 在本地生成或加载。

### 5.3 许愿

「许愿」页提供本地星空背景，可以记录许愿、标记已还愿、恢复为许愿中和删除记录。

该页在**独立全屏窗口**中打开，星空铺满整个画布；重复点击侧栏入口会复用同一窗口，不会开出多个。

### 5.4 纪念日

「纪念日」页支持单次、每年和每月三种重复方式，可设置提前提醒天数并查看下一次发生日期。点击「检查通知」时才会请求通知权限并检查符合条件的提醒。

### 5.5 计算器

「计算器」页提供标准、科学和程序员三种模式：

- 标准模式：四则运算、百分比、平方、平方根、倒数和阶乘等。
- 科学模式：三角函数、对数、幂、模运算、括号和角度模式。
- 程序员模式：按 BIN、OCT、DEC、HEX 输入并进行整数运算。

计算器使用安全的 `AlgebraEvaluator`/Int64 求值路径；阶乘、整数溢出和非法表达式会显示错误，不会通过 Objective-C 异常崩溃。

## 6. AI 功能

### 6.1 配置 AI

打开「设置」（`Cmd+,`）→「AI 分析」标签页：

| 选项 | 说明 |
|------|------|
| 启用 AI 分析功能 | 开关 AI 请求 |
| AI 提供商 | LM Studio / OpenAI / Anthropic |
| 服务器地址 | `http` 或 `https` 地址；官方服务或回环地址可直接使用 |
| Token / API Key | 可选；保存在 macOS 登录钥匙串 |
| 模型 ID | 要使用的模型名称 |
| Temperature | 生成随机性，范围 0–1 |
| 最大 Token 数 | 256–4096，步长 256 |
| AI 服务器支持图像理解 | 打开后，服务具备原生视觉能力时才发送图片 |
| 自定义系统提示词后缀 | 追加到每次 AI 请求的系统提示词 |

### 6.2 服务地址与凭据边界

- API key 不写入 `settings.json`，而是由 `StorageService` 写入 Keychain；旧版本明文 key 会在成功迁移后从设置 JSON 中剥离。
- 官方 HTTPS 服务和回环地址不需要额外确认。
- 第三方服务或远程 `http` 地址需要用户明确勾选信任，并显示 API key 将发送到目标主机的警告。
- 图像理解关闭时，图片先在本机用 Vision OCR 转成文本，再走普通文本请求；图片不会作为多模态负载上传。服务不支持原生视觉且开关已打开时，图片请求会被阻止，而不是静默降级为上传。

## 7. 番茄钟

专注学习计时器：

1. 侧边栏选择「番茄钟」。
2. 在设置中调整专注、短休息和长休息时长。
3. 点击开始、暂停或停止。
4. 专注阶段结束后切换到休息阶段，点击开始后继续下一阶段。

**时长范围（与 UI 一致）：**

- 专注：5–60 分钟，步长 5 分钟；
- 短休息：1–15 分钟，步长 1 分钟；
- 长休息：5–30 分钟，步长 5 分钟。

专注会话会记录有效累计秒数，并提供学习时长和科目统计；通知授权和通知发送失败不会回滚已经记录的学习统计。

## 8. 错题本与背诵卡片

### 8.1 错题本

1. 侧边栏选择「错题本」。
2. 点击「添加」手动录入题目、答案、错误原因、知识点和科目。
3. 复习后选择掌握程度，页面按 `nextReviewAt` 在应用内筛选到期题目。

当前没有为错题本安排系统通知，也不会在后台自动推送题目；复习队列是应用内按到期时间筛选的结果。

### 8.2 背诵卡片

1. 侧边栏选择「背诵卡片」。
2. 点击「添加」手动创建正面、背面和分类。
3. 复习时点击卡片翻转，再选择掌握程度。

`FlashCardService.generateCardsFromContent` 当前只构造生成提示词，函数恒返回空数组，尚未接入资料自动生成流程；因此当前版本以手动创建卡片为主。

## 9. 考试倒计时

1. 侧边栏选择「考试倒计时」。
2. 点击「添加考试」，填写名称、日期、科目和备注。
3. 页面按日期排序并显示剩余天数，临近考试会使用醒目颜色。
4. 过期考试会显示为「已过期」；归档由用户点击归档按钮完成，不会自动归档。

倒计时以 `AppState.examCountdowns` 为唯一真相源，持久化文件为 `examCountdowns.json`。

## 10. PDF 批注

从 PDF 资料详情进入批注页后，可以：

- 选择高亮、下划线、删除线、方框、文本备注、手写 6 种批注工具；
- 选择 6 种颜色；
- 逐页查看并自动保存批注；
- 导出批注为纯文本、Markdown 或 JSON。

批注数据按资料 ID 保存在本地 `pdfAnnotations.json`，导出的内容是批注数据，不是重新写回原 PDF 文件。

## 11. 白板

> **当前版本白板暂时不开放。** 几何画板正在重做，侧栏入口已置灰，进入后显示维护中说明。已有的画板数据仍完整保留，重做完成后可直接继续使用，无需迁移。

以下为重做前的功能说明，仅作参考。

### 11.1 创建与管理

- 首次使用且没有白板文件时创建一个默认画板。
- 可以新建、切换、重命名和删除历史白板。
- 编辑采用防抖自动保存，界面显示正在保存、保存失败或最近保存时间。
- 进入后台和退出前会同步 flush 待保存内容，保存失败时保留待保存状态并显示错误。

### 11.2 绘制与编辑

内置点、圆、弧、多边形、函数图、参数方程、极坐标和测量标记等对象，也支持画笔和橡皮擦。可调整颜色、线条粗细，并使用撤销/重做。

函数图、参数图和极坐标图按数学坐标采样，再转换到白板坐标；输入 `30deg` 等角度后缀可按角度计算。曲线在非有限采样点处分段，渐近线两侧不会用一条跨断点的线强行连接。

## 12. 重复文件清理

1. 侧边栏选择「重复清理」。
2. 选择要扫描的文件夹。
3. 扫描器对 PDF、DOC、DOCX、TXT、MD、PPT、PPTX 建立 SHA-256 索引。
4. 对摘要相同的候选文件再次做流式逐字节内容确认，并排除扫描期间发生变化的文件。
5. 每组重复文件单独确认后，才会将候选文件移入废纸篓；清理前会再次校验内容。

默认保留最早修改的文件；修改时间相同时保留路径最短的文件。当前没有“一次清理所有分组”的无确认操作。

## 13. P2P 社交

「社交」页提供 IPv6 地址和端口、添加好友、文字/群聊、好友公钥指纹、黑名单和后台监听设置。

安全边界如下：

- 握手使用 RSA-2048 公钥交换带版本的会话密钥。
- 新消息使用应用层 AES-256-GCM，提供机密性和完整性；每条消息生成新的随机 96-bit nonce，GCM 标签用于检测密文篡改。
- 首次连接的公钥指纹需要用户在界面中核对并确认；未知或变化的身份不会自动信任。
- 传输层是裸 TCP，没有 TLS、证书式身份验证、防重放保护或防降级保护。
- 旧 AES-CBC 消息只为兼容读取保留，CBC 本身没有认证标签。

因此这里描述的是“应用层加密的 P2P”，不应理解为具备完整端到端安全保证。

## 15. 设置与配置

打开设置（`Cmd+,`），当前有以下标签页：

### 通用

- 日历同步、提醒事项和每日学习通知开关；
- 通知时间、默认学习时长（15–120 分钟）；
- 开机自启动状态；
- 更新检查相关选项；
- “启动时自动扫描”已接入启动扫描逻辑：开关开启且 `scanPaths` 非空时，启动会异步扫描配置路径；当前设置页未提供路径编辑 UI。

### 外观

- 背景图片、模糊半径和透明度；
- 主题选择：经典、国庆红、祥云金、雪山晨曦，详见 [22. 主题与每日祝福](#22-主题与每日祝福)；
- 跟随系统、浅色或深色；
- “显示文件扩展名”已接入资料列表显示。

**背景图片**支持两种来源，可以并存：

- **自己的图片**：点击「添加图片」导入多张，在图片库中点「使用」指定其中一张；
- **随机轮换**：打开后每次启动随机换一张自己的图片，也可随时点「换一张」重抽（自己的图片少于 2 张时该开关不可用）；
- **清空我的图片**：只删除你自己导入的，主题自带素材始终保留。

三个节庆主题会**锁定背景**，强制使用该主题自带的图，此时随机和手动选择不可用；切回「经典」主题后恢复你自己的设置。

**内置素材会被自动恢复。** 主题自带的三张背景图随应用打包，被删除后（清空数据或手动删文件）在下次启动时自动从应用包恢复，主题不会因为缺图而失效。

### 学习

- 学习档案、分析频率、讲解风格、难度、语言风格和记忆类型等偏好。

### AI 分析

- 提供商、服务器、模型、生成参数、图像理解开关、系统提示词后缀和连接测试。
- API key 使用 Keychain；第三方/远程 HTTP 地址需要显式信任。

### 存储

- 资料数量、复习计划数量和数据目录占用空间；
- 清除受管数据文件和受管 Keychain 条目。

### 备份与恢复

- 显示 schema 版本和最近一次启动迁移状态；
- 立即创建 ZIP 备份；
- 查看、删除和恢复历史备份；
- 备份位于数据目录同级的 `SmartNote-Backups`，不会递归把备份打进新备份；
- 恢复前会解压到临时目录并校验关键数据文件，切换失败时回滚原数据目录；
- 备份 ZIP 未加密，需自行妥善保管。

### 关于

- 应用版本与构建号；
- 版权信息。

## 16. 自动更新

应用基于 GitHub Releases 提供更新检查：

- **检查更新**：可手动检查，也可按 1–168 小时间隔自动检查；
- **更新渠道**：Latest 或 Pre-release；
- **自定义仓库**：可配置 Owner/Repo，仓库组件会做格式校验；
- **下载与安装**：自动检查只记录候选版本；用户点击「立即更新」后才下载、解压和安装；
- **安装前校验**：检查 ZIP 结构、Bundle ID、版本和文件数量/大小；
- **旁路切换与回滚**：先复制到同卷旁路目录并复验，再切换目录；切换或启动失败时保留/恢复旧版本；
- **已知限制**：当前没有代码签名信任链，包校验不能替代开发者签名验证。

在「设置 → 通用 → 更新」中配置自动检查、间隔、仓库和渠道；更新日志显示检查、下载、验证和切换过程。

## 17. 快捷键

以下是与当前 `SmartNoteApp` 命令定义和 macOS Settings scene 对齐的快捷键：

| 快捷键 | 当前实际行为 |
|--------|--------------|
| `Cmd+I` | 打开「导入资料」面板 |
| `Cmd+,` | 打开系统设置窗口 |
| `Cmd+Shift+R` | 菜单命令「开始复习计划」当前把 `selectedTab` 设为 2，实际打开「真题」 |
| `Cmd+Shift+K` | 菜单命令「提取考点」当前把 `selectedTab` 设为 1，实际打开「课件」 |

源码中的命令动作直接写入裸数字 tab ID，侧栏顺序变化时容易失效；后续应改为显式页面枚举或统一路由。

## 18. 菜单栏 App 与开机自启

App 启动后通过 `MenuBarExtra` 在菜单栏提供：

- 资料库、番茄钟、待办清单和文件加密入口；
- 快速记录，写入 `Application Support/QuickNotes/<日期>.md`；
- 开机自启开关；
- 打开设置和退出应用。

开机自启使用 macOS 原生 `SMAppService.mainApp.register()`。第一次启用时系统可能弹出批准提示；实际状态以「设置 → 通用 → 系统集成」和菜单栏显示为准。菜单栏本身目前在 `SmartNoteApp` 中注册为常驻 Scene，设置页展示其启用状态。

## 19. 文件加密

侧边栏「文件加密」提供独立的文件加密中心：

- 拖拽或选择不超过 2 GB 的文件；
- 使用 AES-256-GCM 生成 `.snenc` 文件，默认写入源文件同目录，也可选择输出目录；
- 解密时恢复原文件名，目标冲突时追加序号；
- 可选择把每个文件的密码保存到 macOS Keychain，解密时直接读取；
- 加密任务不修改或删除源文件。

技术栈为 `CryptoKit AES.GCM` + `CommonCrypto CCKeyDerivationPBKDF2` + `Security` Keychain。`.snenc` 容器格式为：

```text
[4B magic 'SNEN'][1B version=1][16B salt][12B nonce][ciphertext][16B GCM tag]
```

## 21. 中国近代史科普

「侧栏 → 历史科普 → 中国近代史」提供 1840—1949 的离线学习导览，断网可读。

### 21.1 内容组织

- 首批 34 篇，目录文件为 `SmartNote/Resources/history_catalog.json`，随应用资源打包；
- 采用本项目明确标注的中国大陆常用分期（1840—1949）；
- 「时期」筛选是**主题导览分组**，不作为严格的年份边界，跨时期文章保留在最能帮助理解的主题组中；
- 每篇包含摘要、分段正文、关键事件、人物、名词卡片、关联阅读和来源入口。

### 21.2 阅读与进度

- 搜索标题、摘要、正文、事件、人物、术语和别名；
- 按时期、标签和收藏筛选；
- 文章详情支持分段已读、整篇完成、收藏、最近阅读与随机学习；
- 详情页可调用系统语音朗读正文，离开详情时自动停止；
- 收藏和阅读进度独立保存到 `historyProgress.json`，不会混入资料或 AI 设置。

### 21.3 来源与口径

每篇文章底部列出可继续查证的来源入口，涵盖中国国家博物馆、国家图书馆、社会科学院近代史研究所、故宫博物院、美国国会图书馆与国际联盟档案等机构。涉及数字的表述已核对原始文献并注明统计口径，例如：

- 《辛丑条约》赔款区分本金（4.5 亿两）与本息合计（约 9.8 亿两）；
- 南京大屠杀遇难数字分别标注东京审判判决书与南京军事法庭判决书的依据，不做相加或替代；
- 《南京条约》赔款说明其为第四、五、六款之和。

**内容性质**：正文是基于公开文献整理的**导览稿**，不是逐句转录的原文抄录，来源链接供你自行核对。它不替代教材、档案或专业研究，也不宣称完整覆盖 1840—1949。个别来源链接使用 `http://`（相关机构站点不提供 HTTPS），访问时可能提示不安全。

## 22. 主题与每日祝福

### 22.1 主题

| 主题 | 视觉方向 | 背景行为 |
|------|----------|----------|
| 经典 | 系统原生观感，清晰克制 | 留空或使用你自己的图片 |
| 国庆红 | 深红底、金色强调 | 锁定自带「红金山河」图 |
| 祥云金 | 朱砂与暖金 | 锁定自带「云海金河」图 |
| 雪山晨曦 | 冷调靛蓝与晨光金 | 锁定自带「雪山晨曦」图 |

- 主题选择保存到 `settings.json`，下次启动沿用；
- 经典主题不覆盖系统强调色，并继续遵循「跟随系统 / 浅色 / 深色」；三个节庆主题使用自带的深色对比度方案与全局强调色；
- 主题只改变视觉层，不影响资料、计划、AI、文件处理或 P2P 业务；
- 背景图设置见 [15. 设置与配置 → 外观](#外观)。

### 22.2 每日祝福

- 主界面**底部**显示祝福条，位置固定，不随窗口尺寸变化；
- 按日期从本地祝福库稳定选取，国庆期间（10 月 1—7 日）自动切换为节庆文案库；
- 「换一句」从当前适用库中排除当前条目后另选一条；
- 不联网、不调用 LLM、不写入用户资料，也不触发系统通知；
- 经典主题在非国庆期间默认不显示，以免长期占用界面空间。
