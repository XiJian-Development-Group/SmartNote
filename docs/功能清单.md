## 十、已知边界（这些「不工作」是设计如此，不是 bug）

| 项 | 说明 |
|---|---|
| 白板 | 维护中，代码与数据都保留，重做后恢复 |
| 备份 ZIP | **未加密**，不要当加密快照用 |
| 自更新 | 无 Developer ID 签名与公证，结构校验不等于签名验证 |
| P2P | 裸 TCP，无 TLS / 防重放 / 防降级，不要在公网用 |
| App Sandbox | 未开启 |
| 云同步 | 没有。换电脑请用备份 |
| 背诵卡片 | 资料自动生成卡片未接入，仅支持手动创建 |
| 复习计划农历 | 不接农历表 |
| 纪念日 cron | 不支持，仅单次/每年/每月 |
| 路径扫描设置 | `autoScanDirectories` 已接入但设置页没有路径编辑 UI，默认空路径不触发扫描 |

## 十一、构建与验证

```bash
cd /Users/mofan/Documents/MyProjects/SmartNote
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate xijianBase
xcodegen generate
xcodebuild -project SmartNote.xcodeproj -scheme SmartNote \
  -configuration Debug -destination 'platform=macOS' build
```

Release 归档：

```bash
xcodebuild -project SmartNote.xcodeproj -scheme SmartNote \
  -configuration Release -destination 'platform=macOS' \
  -archivePath Release/SmartNote-2.0.0.xcarchive archive
ditto -c -k --sequesterRsrc --keepParent \
  Release/SmartNote-2.0.0.xcarchive/Products/Applications/SmartNote.app \
  Release/SmartNote.app.zip
shasum -a 256 Release/SmartNote.app.zip
```

**注意**：`Sources/` 下新增文件后必须重跑 `xcodegen generate`（工程用显式文件列表）。
仓库没有 XCTest target，`xcodebuild test` 不可用，不要以它作为验收依据。
